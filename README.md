一个基于第一次结对作业原型实现的「校园失物招领」单页应用：支持发布寻物 / 招领信息、集中浏览、关键词搜索、查看详情与联系方式、由发布者将信息标记为「已找到 / 已归还」。

**下载全部文件后，用谷歌浏览器（Chrome）双击 `index.html` 即可运行，无需安装任何环境。**

---

## 一、功能特性

- **发布信息**：寻物 / 招领一键切换，表单必填校验与逐字段错误提示
- **集中浏览**：首页信息流，支持「寻物 / 招领」分类标签、物品类别筛选、地点筛选、「只看进行中」
- **关键词搜索**：防抖实时搜索 + 热门搜索词 + 空结果引导（清空筛选 / 去发布）
- **查看详情**：物品完整信息 + 发布者联系方式 + **一键复制** + 浏览数统计
- **状态维护**：发布者可在详情页 / 我的发布中把信息标记为「已找到 / 已归还」，可恢复为进行中，可删除；已完成信息自动置灰置底、不再展示联系入口
- **我的发布**：发布统计（共发布 / 进行中 / 已完成）+ 信息管理
- **演示数据**：首次打开自动填充 10 条校园模拟数据；URL 加 `?demo=1` 可体验「我的发布」与状态更新全流程
- **健壮性**：localStorage 不可用时自动降级内存存储；所有用户输入经 HTML 转义渲染，防 XSS

## 三、使用说明

### 1. 运行应用

1. 用**谷歌浏览器（Chrome）**打开 `index.html`；
2. 首次打开会自动加载 10 条演示数据，可直接浏览、搜索、查看详情；
3. 点击底部「发布」→ 填写信息 → 立即发布 → 发布成功；
4. 在「我的发布」中可标记已完成 / 恢复 / 删除。

### 2. 演示模式（推荐给测试人员）

地址栏输入：`index.html?demo=1`

- 将本机模拟为「发布者」，自动在「我的发布」中生成 3 条信息（2 条进行中 + 1 条已完成）；
- 进入详情页可以看到「标记为已找到 / 已归还」「删除」按钮，无需真实发布即可体验完整流程。

### 3. 带关键词打开（可分享的搜索结果链接）

`index.html?q=校园卡` —— 打开即显示「校园卡」的搜索结果。

### 4. 运行单元测试

用谷歌浏览器打开 `test/test.html`，即可看到 47 个测试用例全部通过（91 个断言、0 失败）。

### 5. 重置数据

Chrome 按 `F12` → Application → Local Storage → 删除键名以 `lf_` 开头的记录（`lf_items_v1` / `lf_owner_v1` / `lf_seeded_v1`），刷新页面即可恢复初始状态。

## 四、技术说明

| 项 | 说明 |
|---|---|
| 架构 | 界面层（app.js 入口 + view-*.js 视图）→ 数据层（store.js）→ 持久层（localStorage），逻辑层不依赖 DOM，可被单元测试直接引用 |
| 路由 | 基于 `location.hash` 的简易路由：`#/home` `#/publish` `#/detail/:id` `#/my` |
| 存储键 | `lf_items_v1`（信息列表）、`lf_owner_v1`（本机发布者标识）、`lf_seeded_v1`（播种标记） |
| 状态模型 | `status: active / done` × `type: lost / found` → 寻找中 / 待认领 / 已找到 / 已归还 |
| 兼容性 | 开发与测试统一使用谷歌浏览器；不依赖任何外部 CDN（QUnit 已内置本地） |
