信息状态流转（发布者可操作，状态驱动界面变化）

进行中 active
寻物 → 寻找中
招领 → 待认领
→ 标记为已完成 updateStatus(id, 'done')
已完成 done
寻物 → 已找到
招领 → 已归还
← 恢复为进行中（误标 / 情况变化时） updateStatus(id, 'active')
发布成功时默认状态为 active；标记 done 后详情页不再展示联系入口、列表置灰并排到后面，避免失主被无效联系打扰。
