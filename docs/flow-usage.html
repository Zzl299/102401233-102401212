图 1：用户使用流程图

发布信息 —— 浏览 / 搜索 —— 查看详情 —— 联系发布者 —— 更新状态

① 发布信息流程（寻物 / 招领）
1点击底部「发布」进入发布页
2选择信息类型：寻物 / 招领切换 type-seg
3填写表单：名称 · 类别 · 地点 · 时间 · 描述 · 联系方式
4点击「立即发布」，触发校验Store.isValidPublishData()
校验未通过？ ↺ 高亮错误字段并提示
5修正后重新提交errors 逐字段展示
6校验通过，写入本地存储Store.createItem() → localStorage
7显示「发布成功」页renderSuccess()
8可跳转「我的发布」管理 或 返回首页
② 浏览 / 搜索 / 状态更新流程
1打开首页（自动加载模拟数据）Store.seedIfEmpty()
2浏览列表 · 关键词搜索 · 类别 / 地点 / 状态筛选Store.searchItems()
3点击信息卡片，进入详情页views +1
4查看物品信息 · 一键复制联系方式联系发布者navigator.clipboard / 降级
是本人发布的信息？ ✕ 非本人：仅展示，等待处理
5物品找回 / 归还后，点击「标记为已找到 / 已归还」Store.updateStatus(id,'done')
6状态更新并持久化，可随时「恢复」进行中updateStatus(id,'active')
7首页 / 我的发布中信息置灰，徽标显示「已找到 / 已归还」状态驱动视图重渲染
💡 边界处理：搜索无结果时给出空状态引导「清空筛选 / 去发布」；已完结信息不展示联系入口，避免无效联系。
普通步骤 寻物相关 招领 / 成功 异常分支 结果状态
